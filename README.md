# Virtual Pet Desktop Companion

A lightweight Windows desktop virtual pet application.

## Pets

- Dog
- Hamster
- Pikachu / electric-mouse character
- Ginger Cat

## Core Features

- Desktop pet
- Walk
- Feed
- Sleep
- Grab and throw
- Notes
- Reminders
- System tray
- Windows startup

## Technology

- Tauri
- Rust
- TypeScript
- Three.js
- SQLite
